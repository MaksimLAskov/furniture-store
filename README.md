# МебельМаркет

Интернет-магазин мебели с каталогом, корзиной, оформлением заказов и панелью администратора.

## О проекте

МебельМаркет — учебный frontend-проект интернет-магазина мебели, разработанный на React.

Покупатель может посмотреть каталог, найти нужный товар, открыть его подробную страницу, добавить товары в корзину и оформить заказ.

В проекте также реализована административная часть для управления ассортиментом и обработки заказов.

Текущая версия является клиентским MVP. Товары, корзина, заказы и состояние авторизации сохраняются в LocalStorage браузера. В папке `server` подготовлена основа Express-сервера для дальнейшего подключения REST API и PostgreSQL.

- просмотр главной страницы и популярных товаров;
- просмотр каталога;
- поиск товаров по названию;
- фильтрация по категориям;
- сортировка по возрастанию и убыванию цены;
- просмотр подробной информации о товаре;
- отображение материала, размеров и наличия;
- добавление товаров в корзину;
- изменение количества товаров;
- удаление товаров из корзины;
- автоматический расчёт общей стоимости;
- оформление заказа;
- проверка обязательных полей формы;
- сохранение корзины после перезагрузки страницы;
- страницы с информацией о магазине и доставке;
- обработка пустых состояний и несуществующих маршрутов.

### Для администратора

- отдельная страница входа;
- защищённые административные маршруты;
- дашборд со статистикой магазина;
- просмотр количества товаров и заказов;
- добавление новых товаров;
- редактирование существующих товаров;
- удаление товаров;
- управление названием, категорией и ценой;
- управление описанием, материалом и размерами;
- изменение наличия товара;
- восстановление исходного каталога;
- просмотр оформленных заказов;
- просмотр состава и стоимости заказа;
- просмотр контактных данных покупателя;
- изменение статуса заказа;
- удаление отдельных заказов;
- очистка списка заказов.

## Основной сценарий работы

1. Пользователь открывает каталог.
2. Находит подходящий товар.
3. Переходит на страницу товара.
4. Добавляет товар в корзину.
5. Изменяет количество товаров при необходимости.
6. Заполняет форму оформления заказа.
7. Заказ сохраняется в LocalStorage.
8. Администратор открывает панель управления.
9. Администратор просматривает заказ и изменяет его статус.

## Хранение данных

В текущей версии данные сохраняются локально в браузере:

- товары;
- содержимое корзины;
- оформленные заказы;
- состояние входа администратора.

Пользовательская и административная части используют одни и те же данные. Поэтому созданный заказ сразу появляется в панели администратора, а изменения каталога отображаются в магазине.

## Запуск проекта

Для запуска понадобится Node.js версии 20 или новее.

Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейдите в папку клиентского приложения:

```bash
cd furniture-store-main/furniture-store-client
```

Установите зависимости:

```bash
npm install
```

Запустите проект:

```bash
npm run dev
```

После запуска откройте адрес, который Vite покажет в терминале. Обычно используется:

```text
http://localhost:5173
```

## Доступ в административную панель

Административная панель доступна по адресу:

```text
/admin/login
```

Данные для входа:

```text
Логин: admin
Пароль: admin123
```

Авторизация используется только для демонстрации работы защищённых маршрутов и не предназначена для production-приложения.
