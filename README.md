# Furniture Store

A web application for a furniture store built with React and Vite.

The project includes a product catalog, search and filtering, product pages,
a shopping cart, checkout flow, and an admin panel for managing products
and customer orders.

## Features

- Product catalog
- Search by product name
- Category filtering
- Price sorting
- Product detail pages
- Shopping cart
- Checkout form
- Order management
- Product management
- Protected admin routes
- Local data persistence

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- HTML / CSS
- LocalStorage
- Node.js / Express
